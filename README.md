## Selected Projects

### 🎬 FilmZone

A full-stack movie ticket booking platform built with the MERN stack.

**Highlights**

* Movie discovery and browsing
* User authentication
* Movie booking workflow
* Seat selection and pricing logic
* Admin and vendor roles
* REST API architecture
* MongoDB Atlas integration
* Production deployment

**Stack:** React · Node.js · Express · MongoDB · Tailwind CSS · JWT

---

### 🔗 TempLink

An instant temporary cross-device sharing system designed around browser-based peer-to-peer communication.

**Highlights**

* WebRTC peer-to-peer data transfer
* WebSocket-based signaling
* Temporary sessions
* QR-based device connection
* Text and file sharing
* Session persistence and reconnection handling
* No permanent file storage

**Stack:** Next.js · TypeScript · WebRTC · WebSocket · Zustand · Tailwind CSS

---

### 🏠 Nestora

A modern real-estate marketing website focused on responsive UI, animation, visual storytelling, and reusable component architecture.

**Stack:** Next.js · TypeScript · Tailwind CSS · Framer Motion

---

### 💱 RateFlow

A currency conversion and exchange-rate visualization application using external financial APIs.

**Highlights**

* Currency conversion
* Historical exchange-rate charts
* Live currency comparison
* Recent rate movement
* External API integration
* Responsive React architecture

**Stack:** React · TypeScript · Vite · Tailwind CSS · Recharts

---

### 🎮 FourPlay

A Flutter implementation of the classic Connect Four game.

**Highlights**

* 7 × 6 game board
* Two-player local gameplay
* Turn management
* Horizontal, vertical, and diagonal win detection
* Draw detection
* Reactive state management

**Stack:** Flutter · Dart · GetX
